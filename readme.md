Была необходимость скачать книгу с одной популярной онлайн-библиотеки.
К сожалению, скачать нельзя, но можно посмотреть.
Записав видео с четко известными интервалами перелистывания страницы (например, используя AutoHotkey), можно ее загнать в программу и разбить на фреймы, а затем их собрать в PDF-файл и распознать текст.
